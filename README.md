# Li Deng portfolio

Static HTML/CSS/JavaScript implementation of the supplied Figma design. It has no build step and is ready for GitHub Pages.

## Customize

- Review the résumé-based biography, projects, work history, and contact details in `index.html`.
- Replace each striped image placeholder with an `<img>` using the same class or dimensions.
- Add your resume as `resume.pdf` in the project root.
- Replace every placeholder `href="#"` with the appropriate URL.

## Publish on GitHub Pages

1. Create a GitHub repository and copy these files into its root.
2. Commit and push to the `main` branch.
3. Open **Settings → Pages** in GitHub.
4. Choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Save and wait for GitHub to provide the public URL.
